### `PredictionService`

*   **`predict_lap_time(year, race, driver)`**
    *   **Success:**
        ```json
        {
          "predicted_lap_time": 88.345
        }
        ```
    *   **Error:**
        ```json
        {
          "error": "Model not loaded. Please train the model first."
        }
        ```
